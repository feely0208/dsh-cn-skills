# 国内应用市场上架预检

面向**提交应用市场之前**的一次体检：从上架材料的角度，把会被驳回的地方先找出来。

它和相邻技能的分工是刻意分开的：

| 技能 | 管什么 |
| --- | --- |
| `dsh-cn-appstore-preflight`（本技能） | **材料齐不齐、上架流程能不能过** |
| `dsh-cn-pipl-check` | 隐私**声明与实现**是否一致 |
| `dsh-cn-compliance` | 对外**文案**红线 |
| `dsh-cn-ai-labeling` | AI 生成内容的**标识** |

本技能**不下场重复检查**上面三件事，而是在需要时把它们的结果收进来当输入。

## 一、何时用

- 准备首次上架，或版本更新要重新提交审核时
- 被驳回后，定位驳回原因时
- 要为新市场（华为 / 小米 / OPPO / vivo / 应用宝 / 鸿蒙）准备材料时

## 二、先跑取证脚本

```bash
<scan.sh 路径> --dir /path/to/app
```

脚本会取证并输出**上架材料清单骨架**：包名与 targetSdk、App 备案号是否在 App 内可见、
隐私政策入口、权限清单与用途说明、账号注销入口、未成年人保护机制。

## 三、六个必查项

### 1. App 备案（**没做就别提交**）

工业和信息化部对移动互联网应用程序的备案要求 —— **网站 ICP 备案与 App 备案是两件事**，
不能互相替代。常见驳回原因就是把网站的备案号填到 App 备案那一栏。

自检：
- App 内是否有「关于 / 设置」能看到备案号？
- 填进市场后台的备案号，是否就是**这个 App** 的备案号？

### 2. 隐私政策：可达 + 一致

两件事都要满足：

| 要求 | 怎么验 |
| --- | --- |
| **可达** | 从 App 内能打开；链接公网可访问（别只放本地文件） |
| **一致** | 政策里写的权限/SDK/收集范围，与代码实现一致 → 跑 `dsh-cn-pipl-check` |

> 政策链接打不开、或政策里承诺的注销入口在 App 里找不到，都是高频驳回项。

### 3. 权限：最小必要 + 有「使用场景说明」

市场通常要求为每一个权限说明**为什么需要**（申请该权限对应的功能场景）。准备方式：

| 权限 | 使用场景（示例写法） |
| --- | --- |
| 相机 | 用于拍摄证件/上传头像，在「XX」功能中由用户主动触发 |
| 定位 | 用于显示附近门店，仅在使用该功能时申请 |
| 存储 | 用于保存用户导出的文件 |

自检：**不给这个权限，核心功能还能用吗？** 能，就不该要。

### 4. 账号注销入口

有账号体系的产品，必须有**用户可自助完成**的注销路径。多数市场不接受"发邮件申请"。

### 5. 未成年人保护

面向未成年人、或含社交/游戏/直播/内容社区元素的产品，通常需要相应的保护机制与说明
（如青少年模式、监护人同意、时长限制）。按产品实际情况准备。

### 6. 材料齐备

见下面第五节的清单骨架。最容易漏的是**软著证书**和**第三方 SDK 清单**。

## 四、常见驳回原因（按出现频率）

1. 隐私政策不可达，或与实现不一致
2. 无账号注销入口
3. 权限申请与功能无关，或申请时机不当（一启动就要）
4. App 备案缺失，或填了网站的 ICP 备案
5. 截图/描述文案踩红线（→ 跑 `dsh-cn-compliance`）
6. 第三方 SDK 未在清单里披露
7. 版本号未递增 / 与后台填写不一致

## 五、上架材料清单骨架

脚本会自动打印这一节，也可照这里准备：

**基本信息**：应用名称、包名、版本号与 versionCode（**每次提交必须递增**）、图标、截图、分类、简介

**资质与备案**：App 备案号、软著证书、特殊行业许可证（如适用）

**隐私与权限**：隐私政策链接、权限使用场景说明、第三方 SDK 清单、个人信息收集与共享清单、账号注销路径说明

**内容与合规**：截图与文案（过 compliance）、AI 生成内容标识材料（如适用）、未成年人保护说明（如适用）

## 六、纪律

- **以官方最新公告为准**。各应用市场的要求**不同且会变**，本技能给的是通用骨架，
  **不是**任何一家市场的官方清单。正式提交前务必核对目标市场的当前要求。
- **不杜撰具体条款**。不确定的地方说"需要核实"，不要编一条看起来很像的规定出来。
- **驳回不等于产品有问题**。有时只是材料写法问题 —— 先看驳回理由，再决定改代码还是改材料。
- **不要把本技能当法务意见**。它是一份准备清单，不构成法律意见。
